# Fluxzee Hotelaria

Repositório de ativos da vertical de hotelaria da Fluxzee.

## Estrutura

```
fluxzee-hotelaria/
├── logo/                          # Logos SVG e PNG
├── lp/                            # Landing page (Cloudflare Pages)
├── identidade-visual/             # Guia de marca
└── conteudo-instagram/            # Copies e roteiros
```

## Deploy

Landing page em `lp/index.html` — deploy via Cloudflare Pages Direct Upload.

## Stack

- Landing page: HTML puro
- Logo: SVG vetorial puro
- Automação: n8n + Claude API + Notion
